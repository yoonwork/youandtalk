계정과 데이터 삭제 준비

앱이나 창을 닫는 것과 계정·데이터 삭제는 같은 일이 아니에요. 서비스 안내를 확인하고 순서대로 정리해요.

온다톡 시작하기

먼저 이용 형태를 확인해요

회원 계정으로 썼는지, 로그인 없이 이용했는지부터 구분하세요. 소셜 로그인을 사용했다면 카카오나 구글 등 어떤 방식으로 연결했는지도 확인해요. 브라우저 방문 기록이나 바로가기를 지우는 것만으로 서비스 계정이 삭제된다고 생각해서는 안 돼요.

삭제 전에 필요한 것만 정리해요

  • 처리 중인 신고나 문의가 있다면 관련 화면과 접수 내용을 보관해요.
  • 결제 또는 포인트 관련 확인이 필요하면 내역을 먼저 살펴요.
  • 친구 연결이나 커뮤니티에 남긴 활동 가운데 직접 정리할 항목이 있는지 확인해요.
  • 같은 비밀번호를 다른 서비스에서도 썼다면 그곳의 비밀번호도 별도로 바꿔요.
  • 삭제 뒤 다시 확인해야 할 자료가 없는지 마지막으로 점검해요.

불필요한 대화 내용을 따로 복사해 오래 보관할 필요는 없어요. 다른 사람의 개인정보가 포함된 기록은 공개하거나 공유하지 마세요.

공식 삭제 안내를 따라요

메뉴 이름과 처리 방식은 서비스마다 달라요. 개인정보 처리방침과 계정 삭제 안내에서 대상 데이터, 본인 확인 방법, 처리 절차를 읽고 진행하세요. 이해되지 않는 부분은 운영 문의처에 확인하고, 삭제가 끝났다는 안내가 있다면 필요한 기간만 보관해요.

삭제 후에도 점검해요

브라우저에 저장된 로그인 정보와 자동 완성을 확인하고, 소셜 계정의 연결 서비스 목록도 살펴보세요. 의심스러운 접속이나 결제가 있었다면 계정 삭제만으로 끝내지 말고 해당 로그인·결제 제공자와 관련 공식 기관에 문의해요.

온다톡을 정리하려면
